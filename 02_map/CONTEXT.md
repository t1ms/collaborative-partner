# 02_map — Distilled Cognitive Models

One job: distill the canonical research into modular, agent-consumable cognitive models and verification protocols.

## Inputs
- Working: None (stable reference library).
- Reference: `../01_source/bandler-nlp-thinking-partners.pdf` and `../01_source/NLP Derivatives and Empirical Validity.docx`.

Do NOT load: agent implementation details or Cloud Run configurations from `03_agent-system/`.

## Process
1. Extract distinct cognitive mechanisms into standalone markdown modules.
2. Apply de-branding protocol (`VERIFICATION.md`): strip pseudoscience and therapy framing, positioning as structured Socratic problem clarification.
3. Keep each module within the 2,000–8,000 token range.

## Outputs
- `meta-model.md` — Ingestion classifier and precision question router.
- `well-formed-outcomes.md` — Outcome sieve with testable exit conditions.
- `five-phase-pipeline.md` — State machine transition ontology.
- `reframing.md` — Lateral thinking & perspective shifting models.
- `submodalities.md` — Internal representations and diagnostic models.
- `demo-dialogues.md` — Evaluation case dialogues.
- `VERIFICATION.md` — De-branding and empirical framing rules.
- `INDEX.md` — Map module index.

## Human check
Verify that each module is faithful to the source paper, contains no invented mechanisms, and complies with de-branding guidelines.
