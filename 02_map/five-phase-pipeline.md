# The 5-Phase Operational Pipeline & State Machine

Source: paper §7. The deterministic execution engine for the Thinking Partner.

## Phases

1. **INGESTION** — Parse user input with Meta-Model sieve. Extract: nominalizations (→ flag for re-verbing), missing referential indices, missing comparative baselines, unspecified verbs, modal operators (necessity/possibility), complex equivalences (X ≡ Y), cause-effect (X → Y).
2. **DESTABILIZATION** — Decision gate:
   - Condition A (cognitive loop / panic / spiraling) → pattern interrupt or grotesque exaggeration.
   - Condition B (analytical ambiguity / nominalized confusion) → precision Meta-Model questioning.
   - Condition C (submodality paralysis) → submodality shift (dissociate, shrink image, mute internal dialogue).
3. **OUTCOME ARCHITECTURE** — Apply the WFO sieve: positive formulation, user-controlled domain, sensory calibration, chunk-size management.
4. **MULTI-ANGLE GENERATION** — Perceptual positions rotation (1st–4th), Sleight of Mouth reframing, temporal backcasting (prospective hindsight from t+10y).
5. **ECOLOGY & COMMIT** — Secondary-gain audit, pre-mortem simulation ("place yourself next Monday morning in the trigger environment — what friction arises?"), lock an observable 24-hour micro-action, exit.

## State-transition table

| State | Trigger | Next state | Protocol |
|---|---|---|---|
| INGEST | Vague complaint w/ nominalizations ("I'm stuck in my career") | CLARIFY | Re-verb: query process mechanics, agents, time boundaries |
| INGEST | High-arousal spiral ("everything is collapsing") | INTERRUPT | Grotesque exaggeration / pattern interrupt to crash the loop |
| CLARIFY | Friction point now clear, locus unclear | WFO | Apply the 5 predicates |
| WFO | Outcome stated as absence ("I don't want to burn out") | WFO | "What specific schedule/state will you maintain instead?" |
| WFO | All 5 predicates verified | LATERAL | Perceptual positions + Sleight of Mouth |
| LATERAL | Deadlock persists in 1st position | LATERAL | Shift to 2nd (counterpart) then 3rd (observer) position |
| LATERAL | ≥3 high-utility alternatives generated | ECOLOGY | Ecological audit + pre-mortem |
| ECOLOGY | Secondary-gain conflict ("I'll lose my free time") | CLARIFY | 6-step reframing: decouple intent from strategy |
| ECOLOGY | Ecological clearance, clean simulation | COMMIT | Lock 24h micro-action; calibrate; exit |

## TOTE cybernetics (underlying loop model)

Test → Operate → Test → Exit. "Stuckness" = one of three pathologies:
1. **Degenerate exit** — criterion framed as an absence ("exit when zero anxiety") → infinite loop.
2. **Faulty calibration / null operator** — same operator repeated while error doesn't decrease ("worrying harder").
3. **Incompatible test predicates** — testing feelings while operating on self-talk, no bridge between modalities.
