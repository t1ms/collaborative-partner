## Framing Angles
- **Primary Observer (3rd Position):** First-time user / support transcript / session replay evaluator.
- **Counterparty (2nd Position):** Confused first-time user encountering the empty state or form error.
- **Evidence Sources:** Task completion rate, drop-off funnel, click path replay, user testing video snippet.
- **Orientation Rationale:** Let's look at this directly through the first-time user's journey and interaction friction.

## S4 Perspectives
- **1st Position (Direct Owner):** Product designer orchestrating intuitive mental models and clear task flows.
- **2nd Position (Counterparty):** First-time user without prior context attempting to complete the core job.
- **3rd Position (Objective Data):** Session replay observer — tracking mouse trajectories, hesitation pauses, and drop-off steps.
- **Reframe:** Interaction Affordance Reframe — treating user churn not as user error, but as an ambiguous visual affordance.
